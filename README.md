# Medical Insurance Cost Prediction

A Deep Learning application that predicts medical insurance costs based on customer information.

## Features

- Age Input
- Sex Input
- BMI Input
- Children Input
- Smoker Status
- Region Selection
- Insurance Cost Prediction

## Technologies

- Python
- TensorFlow / Keras
- Pandas
- Scikit-Learn
- Streamlit

## Run

pip install -r requirements.txt

streamlit run app.py
